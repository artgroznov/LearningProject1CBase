# Нетиповая конфигурация 1С «Салан красоты» 1.0.0.1

---
> Мой итоговый проект по направлению 1С разработчик.  
> 
**Описание:**

Проект реализован в платформе 1С:Предприятие 8.3. Реализована базовая архитектура системы управления салоном красоты.

**Ключевые возможности:**  

В состав конфигурации включена Библиотека стандартых подсистем (БСП). Используемые подсистемы:
- Базовая функциональность
- Обновление версии ИБ
- Пользователи
- Организации
- Печать
- Дополнительные отчеты и обработки

Разработаны справочники и вспомогательные объекты конфигурации  
Разработаны документы и регистры, документы формируют движения по соответствующим регистрам  
Разработан механизм ввода на основании для документа Реализации  
Разработана печатная форма для документа Реализации  
Разработан оперативный учет организации:
- Разработан расчет себестоимости товаров при их списании (по средней)
- Разработан контроль остатков товаров и материалов на складе

Настроен пользовательский интерфейс конфигурации

**Технологический стек:**
*   1C:Enterprise 8.3
*   Управляемые формы (managed forms)
